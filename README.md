## 🔭 What I'm Building
**[FormAI](https://github.com/leticiaborges/form-ai)** turns pasted text or an uploaded document
(PDF, DOCX, PPTX or TXT) into a question form that can be edited, shared and scored.

🔗 **Live demo:** [formai.leticiaborgesdev.com](https://formai.leticiaborgesdev.com), no sign-up needed, just click **Try demo**.

Stack: .NET 10, Entity Framework Core, PostgreSQL, SignalR with a Redis backplane, React, TypeScript,
Tailwind CSS, xUnit, NSubstitute, Vitest, Playwright, GitHub Actions, Docker, and AWS (ECS Fargate,
RDS, CloudFront, Route 53) provisioned with Terraform.
